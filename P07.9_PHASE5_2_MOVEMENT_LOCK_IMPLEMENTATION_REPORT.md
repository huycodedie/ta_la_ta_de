## 6. Cast/Channel Behavior

- **Cast-Time Skills (`CastTime > 0`)**:
  - `ExecuteSelectedSkill` -> `IsCasting == true` -> `CanMove == false`.
  - Movement is blocked immediately upon cast start.
  - Transform position remains completely frozen during cast progression.
  - Upon cast completion, `IsCasting == false` -> `CanMove == true` (if no CC blocks movement), and movement resumes normally.
- **Channel Skills (`IsChannel == true`)**:
  - Channel start -> `IsCasting == true` -> `CanMove == false`.
  - Movement remains locked for the entire duration of the channel.
  - Periodic channel ticks do not unlock movement.
  - Upon channel completion, `IsCasting == false` -> `CanMove == true`, and movement resumes toward target.
- **Instant Skills (`CastTime == 0`)**:
  - Executes immediately without leaving residual casting state or movement locks.

---

## 7. Root Behavior

- **Root Coexistence with Cast**:
  - Root applied during active cast does **not** interrupt casting (per P07.9-D05 / Section 10 TEST 14).
  - Movement remains blocked during cast (`CanMove == false`).
  - Upon cast completion, cast ends (`IsCasting == false`), but `StatusController.CanMove == false` due to Root.
  - Movement continues to be blocked until Root expires.
  - When Root expires, `CanMove == true` and movement resumes.

---

## 8. Stun / Freeze Behavior

- **Hard-CC Interruption**:
  - When Stun or Freeze is applied during cast/channel, `InterruptCurrentAction` terminates the active cast.
  - `IsCasting` immediately becomes `false`.
  - However, `StatusController.CanMove` is `false` due to Stun/Freeze.
  - Therefore, `CanMove` remains `false`.
  - After Stun/Freeze duration expires, `CanMove` returns to `true`, and movement resumes.

---

## 9. Dash Behavior

- `Entity.CanDash` returns `false` during active casting and channeling.
- Dash capability permission is locked during cast, preventing any dash action if invoked.
- No new dash mechanics or parallel systems were introduced.

---

## 10. Death / Revive Behavior

- If an entity dies during cast/channel:
  - Cast state is released (`IsCasting == false`).
  - Movement is prevented because `Entity.IsAlive == false` (checked by `MovementComponent`).
- After Revive:
  - `Entity.IsAlive == true`, `IsCasting == false`.
  - No lingering cast movement lock exists.
  - Movement resumes toward target unless another CC blocks it.
