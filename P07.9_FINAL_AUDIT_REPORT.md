## 4. Cast Time Audit

- **`SkillDefinitionSO`:** Contains `castTime`, `CastTime`, and `IsInstant => CastTime <= 0f && !isChannel`.
- **`SkillCastState`:** Manages deterministic phases (`Ready`, `Casting`, `Channeling`, `Recovery`, `Interrupted`). `StartCast` initializes timers idempotently.
- **`SkillExecutor`:** Step 1 validates; Step 2 consumes Rage; Step 2.5 transitions into `StartCast` with callback `ExecuteCastComplete`. Effects execute strictly upon completion.
- **Idempotency & Safety:** `hasCompleted` flag in `SkillCastState` ensures `OnCastCompletedCallback` and effect pipeline execute exactly once.

---

## 5. Channel Audit

- **Fields:** `isChannel`, `channelDuration`, `channelTickInterval`.
- **Progression:** Driven by `ElapsedChannelTime`. Intermediate ticks execute deterministically at `(ChannelTicksExecuted + 1) * ChannelTickInterval`.
- **Multi-Tick Safety:** `while (!hasCompleted && CurrentPhase == SkillCastPhase.Channeling)` in `SkillCastState.TickChannel()` guarantees that if a large `deltaTime` crosses multiple tick boundaries in a single frame, all scheduled ticks execute without omission.
- **Rage & Cooldown:** Rage is consumed once at channel start; cooldown triggers only after channel duration completes successfully.

---

## 6. Runtime Tick Audit

- **Path:** `Entity.Update()` -> `TickActiveCast(GetDeltaTime())` -> `SkillCastState.Tick(deltaTime)`.
- **Single Authority:** Zero coroutines, zero global ticking managers, zero Animator event dependencies.
- **Component Harmony:** `AttackComponent`, `MovementComponent`, and `EntityStatusController` update loops run independently without overriding or desynchronizing `CastState`.

## 7. Re-entry Audit (Active Cast Guard)

- In `SkillExecutionValidator.cs` (lines 56–62):
  ```csharp
  if (source.IsCasting)
  {
      failureReason = SkillExecutionFailureReason.SourceAlreadyCasting;
      failureMessage = $"Source entity '{source.EntityName}' is already casting.";
      return false;
  }
  ```
- **Safety:** An ongoing Cast A cannot be overwritten by a subsequent Skill B request. Skill B is rejected immediately; 0 Rage is deducted for B; Cast A completes or interrupts normally.

## 8. Interrupt Audit

- **Hard CC Interruption:** Stun and Freeze invoke `OwnerEntity.InterruptCurrentAction(SkillCastInterruptSource)`.
- **Isolation:** Root and Ordinary Damage do NOT interrupt active casts or channels.
- **Anti-CC & Resistance:** Active Anti-CC immunity blocks Stun/Freeze application, preserving ongoing casts. CC Resistance reduces duration without corrupting interrupt triggering.
- **Invariants:** Interruption is idempotent; deferred effects are canceled; cooldown is not applied; Rage is not refunded.
