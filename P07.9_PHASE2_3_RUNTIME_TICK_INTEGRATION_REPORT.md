## 3. Existing Unity Lifecycle Audit

As confirmed in Phase 2.2:
- The game relies on a **decentralized, component-based Unity lifecycle**:
  - `AttackComponent.Update()`: Advances basic attack timer (`attackTimer += Time.deltaTime`).
  - `MovementComponent.Update()`: Displaces position toward targets using `Time.deltaTime`.
  - `EntityStatusController.Update()`: Ticks buffs, debuffs, crowd controls, shields, and DoTs.
- `BattleManager` and `GameManager` do not possess `Update()` loops.
- `Entity.cs` was the missing link where `TickActiveCast(Time.deltaTime)` needed to be anchored to bridge Unity frame timing to `SkillCastState`.

## 4. Implementation Changes

To establish the minimal runtime cast tick bridge without adding managers, coroutines, or loops:

1. **`Assets/_Game/Entities/Entity.cs`**:
   - Added `using WuxiaGame.Core;` for `BattleManager` access.
   - Made `TickActiveCast` virtual to allow deterministic lifecycle interception in test environments:
     ```csharp
     public virtual void TickActiveCast(float deltaTime)
     {
         if (CastState != null && CastState.IsActive)
         {
             CastState.Tick(deltaTime);
         }
     }
     ```
   - Added `protected virtual void Update()` implementing the minimal runtime bridge with all required authority guards:
     ```csharp
     protected virtual void Update()
     {
         if (BattleManager.Instance != null && !BattleManager.Instance.IsBattleActive)
             return;

         if (!IsAlive || !IsCasting)
             return;

         TickActiveCast(Time.deltaTime);
     }
     ```

2. **`Assets/_Game/Editor/Prototype01PlayTestRunner_P07_9_Phase2_3.cs`**:
   - Implemented 12 dedicated automated unit/integration tests (TEST 01 -> TEST 12).
   - Implemented real Play Mode Acceptance Scenario (`RunPrototype07_9PlayModeAcceptanceTests`) validating Section 11 requirements.

## 5. Runtime Tick Call Chain

The complete runtime call chain now functions as follows:

```
Unity Engine PlayerLoop (Every Frame)
 ├──> AttackComponent.Update()       -> attackTimer += Time.deltaTime
 ├──> MovementComponent.Update()     -> displacement using Time.deltaTime
 ├──> EntityStatusController.Update()-> Tick(currentTime)
 └──> Entity.Update()
       │
       ├──> Guard 1: BattleManager.Instance != null && !BattleManager.Instance.IsBattleActive -> return;
       ├──> Guard 2: !IsAlive || !IsCasting -> return;
       │
       └──> Entity.TickActiveCast(Time.deltaTime)
             │
             └──> SkillCastState.Tick(deltaTime)
                   │
                   ├──> ElapsedTime += deltaTime
                   ├──> RemainingTime -= deltaTime
                   └──> if (ElapsedTime >= CastDuration) -> CompleteCast()
                         └──> SkillExecutor.ExecuteCastComplete(this)
                               ├──> EffectResolver.ResolveEffects(...)
                               └──> CooldownManager.TriggerCooldown(...)
```
