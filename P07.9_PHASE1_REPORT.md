## 2. Architecture Audit

Confirmed single runtime authority structure:
- **Skill Execution Authority**: [SkillExecutor.cs](file:///E:/code/TLTD/Assets/_Game/Combat/SkillExecutor.cs) is the sole authority for skill execution.
- **Effect Authority**: `EffectResolver.cs` is the sole pipeline for resolving and applying effects.
- **CC Authority**: [EntityStatusController.cs](file:///E:/code/TLTD/Assets/_Game/Combat/EntityStatusController.cs) is the sole authority for CC, resistance, Anti-CC, and permission queries (`CanUseSkill`, `CanUseUltimate`, `CanMove`).
- **Resource Authority**: `RageComponent.cs` is the sole authority for Rage.
- **Cooldown Authority**: `CooldownManager.cs` and `MindMethodManager.SkillRuntimeState` are the sole authorities for Cooldown.
- **Damage & HP Authority**: `DamageCalculator.cs` and `HealthComponent.cs` (with shield interception in `EntityStatusController`) remain the sole damage pipeline.
- **No duplicate authorities created**: Zero parallel executors, zero duplicate CC systems, zero duplicate cooldown/Rage managers.

## 3. Existing Skill Execution Flow

```
Hero.ExecuteSelectedSkill(slot, target)
  → SkillExecutionRequest created
  → SkillExecutionValidator.Validate(request)
      ├── CC check: CanUseUltimate (if Ultimate) or CanUseSkill (if regular)
      ├── MindMethod / Unlock / Selection validation
      ├── Target alive / opposition validation
      ├── Cooldown check via CooldownManager
      └── Rage cost check via RageComponent
  → SkillExecutor.ExecuteSkill(request)
      ├── RageComponent.ConsumeRage()
      ├── EffectResolver.ProcessEffects()
      ├── CooldownManager.TriggerCooldown()
      └── EventBus notifications (Requested, Succeeded, Failed)
```
Existing instant skill execution remains 100% intact, synchronous, and single-frame.

## 4. Runtime Cast State Design

Implemented minimal, deterministic foundation class:
- **[SkillCastState.cs](file:///E:/code/TLTD/Assets/_Game/Combat/SkillCastState.cs)**:
  - `SkillCastPhase`: `Ready = 0`, `Casting = 1`, `Channeling = 2`, `Recovery = 3`, `Interrupted = 4`.
  - `SkillCastInterruptSource`: `None = 0`, `CrowdControl = 1`, `CasterDeath = 2`, `ManualCancel = 3`.
  - Minimal tracking: `CurrentPhase`, `ActiveRequest`, `CastDuration`, `ElapsedTime`, `StartTime`, `IsInterruptible`, `InterruptSource`.
  - Computed helpers: `RemainingTime` (strictly clamped `>= 0`), `Progress` (0..1), `IsActive`, `IsFinished`.
  - Methods: `StartCast(request, duration, startTime, interruptible)`, `Tick(deltaTime)`, `Interrupt(source)`, `TransitionToChanneling()`, `Complete()`, `Reset()`.
  - **Boundary invariant**: `SkillCastState` does NOT execute `EffectResolver`, does NOT modify `HealthComponent`, does NOT duplicate `CooldownManager`, and does NOT store or consume `Rage`.
